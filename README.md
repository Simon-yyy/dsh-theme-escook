## ✨ Features

- 🎨 **Signature Dark Aesthetics**: Faithful port of the beloved VS Code `escook-theme` color palette (`#1f2430` deep night base with `#ffcc66` amber gold accent).
- 💻 **Syntax Highlighting**: Enhanced code readability with vibrant pastel tones (Pink keywords, Cyan functions, Mint strings, Amber numbers).
- ⚡ **Full UI Coverage**: Seamlessly styles sidebar, chat bubbles, settings panels, marketplace cards, and scrollbars.
- 🔄 **Live Hot Toggle**: Instant switch in DSH Market Theme tab without server restart.

---

## 📦 Installation

```bash
dsh plugin --profile web add dsh-theme-escook
```
