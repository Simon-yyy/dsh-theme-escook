## ✨ 主题特性

- 🎨 **经典暗色美学**：深度复刻 VS Code 最受喜爱的 `escook-theme` 调色板（深紫暗夜 `#1f2430` 底色 + 标志性琥珀明黄 `#ffcc66` 强调色）。
- 💻 **极客代码高亮**：粉红关键字、天蓝函数名、薄荷绿字符串与鲜橙常量，高对比度护眼舒适。
- ⚡ **全组件覆盖**：侧边栏、对话气泡、设置面板、插件市场、弹窗与滚动条均得到原生级深度适配。
- 🔄 **热插拔切换**：在插件市场“主题”页一键点选切换，无需重启即时生效。

---

## 📦 安装使用

### 方法一：通过 DSH 插件市场安装（推荐）
1. 打开 DeepSeek Harness 桌面端 / Web；
2. 进入 **设置 → 插件市场 → 主题** 专区；
3. 搜索 **`dsh-theme-escook`** 并点击 **安装**，点选即可立即生效！

### 方法二：命令行一键安装
```bash
dsh plugin --profile web add dsh-theme-escook
```
